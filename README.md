# 🎧 Spotify Web UI Clone

A minimal, responsive **Spotify-style music player interface** built for the web. Features core sections like Home, Search, Library, and Trending Charts, providing a sleek browsing experience.

---

## 🚀 Features
- Spotify-inspired UI with Home, Search, Your Library, and Browse pages  
- Trending Charts for discovering popular tracks  
- Responsive design for desktop and mobile  
- Smooth navigation and clean layout  

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript**
